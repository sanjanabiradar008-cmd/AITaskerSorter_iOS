# AITaskSorter-iOS

A native iOS utility that demonstrates how a mobile client interfaces with an automated AI backend system like n8n or Make.com.

## 🤖 AI Automation Architecture
- **Webhook Integration Ready:** The interface action trigger mimics a secure HTTP POST request payload routed directly to an n8n Webhook node.
- **Asynchronous Data Visualization:** Leverages dynamic loading properties (`ProgressView`) to handle automated server response streams fluidly.
- **State Manipulation Routing:** Displays real-time category updates and priority logic processing fields returned from the mock language model backend.

## 🛠️ Technical Stack
- **Language:** Swift 5.x
- **Framework:** SwiftUI
- **Target OS:** iOS / iPadOS
